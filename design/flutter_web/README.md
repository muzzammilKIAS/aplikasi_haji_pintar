Flutter web mockup for the 'Elegant' redesign

How to run (requires Flutter SDK):

1. Install Flutter: https://flutter.dev/docs/get-started/install
2. From the repository root:
   cd design/flutter_web
   flutter pub get
   flutter run -d chrome

This is a small standalone Flutter project contained in design/flutter_web so it won't
interfere with your main repo's Dart/Flutter setup. If your repo already contains a Flutter
app and you want these widgets integrated into that project, tell me the path to the
existing Flutter app (for example: `mobile/` or `flutter_app/`) and I will convert
these files into components and open a PR.
